Expression SQL cards

Shape

Every query declares input columns, may name shared expressions with WITH, then returns projections or aggregates from SELECT.

INPUT (price f64, discount f64, keep bool);
WITH revenue = price * (1.0 - discount)
SELECT
  revenue AS net,
  sum(revenue) FILTER (WHERE keep) AS kept_net;

Column types

Supported data types: i8, i16, i32, i64, f32, f64, bool. Add ? when an input can be null.

INPUT (
  qty i32?,
  flags i32,
  ok bool
);

Numbers

Casts: i64(x).Helper functions: abs, sqrt. Use least(a,b) or greatest(a,b) for scalar min/max.

WITH gross = i64(qty) * i64(price)
SELECT
  least(greatest(a, lo), hi) AS clamped,
  abs(delta) AS magnitude,
  sqrt(x * x + y * y) AS norm;

Predicates

Comparisons produce masks. Combine them with AND, OR, and NOT, then feed them to ifelse, filters, or boolean outputs.

WITH keep = qty > 0 AND price <= 5000
SELECT
  ifelse(keep, i64(price), 0) AS safe_price;

Aggregates

sum, min, max, and count_if can be returned next to normal projections; add FILTER to aggregate selected rows.

SELECT
  sum(value) AS total,
  min(value) FILTER (WHERE valid) AS min_valid,
  count_if(valid) AS valid_rows;

Nulls

Nullable inputs carry validity with the value. Use IS NULL, IS NOT NULL, coalesce, and nullif to make the row policy explicit before projecting or aggregating.

WITH
  price = nullif(unit_price, 0),
  safe_qty = coalesce(qty, 0)
SELECT
  price IS NOT NULL AS has_price;
