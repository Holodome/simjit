Compile timing

How compile time is measured

Compile time is measured separately from the hot runtime loop, so one-time setup costs don't contaminate execution samples.

Python API rows

Median time to produce a runnable kernel from already-created NumPy/Arrow inputs and an expression. Covers the full native path (type resolution, lowering, codegen). Excludes input data generation and hot-loop execution.

AsmJit rows

Median native compile time after Python hands off. Covers lowering and AsmJit codegen. Excludes Python overhead, harness compilation, and execution, but will be larger than pure C++ usage due to Python handoff costs.

LLVM rows

Median native compilation time from HIR in an initialized JIT session until compilation returns a callable function pointer (O1 for SIMD/scalar LLVM rows, O3 for the scalar-O3 row).

C++ emitter rows

C++ emitter rows do not report compile time to avoid creating a strawman.
